## P1 — Solo presenter (primary)

| Attribute | Detail |
|-----------|--------|
| Goal | Read script smoothly while recording or presenting |
| Device | Phone as prompter; laptop for script prep |
| Pain | Copy/paste between devices is clumsy |
| Needs | Large text, speed control, fullscreen, mirror, offline reliability |
| Journey | J2 relay or J2b QR → mobile prompter |

---

## P2 — Streamer / creator

| Attribute | Detail |
|-----------|--------|
| Goal | Same as P1 with minimal setup friction |
| Device | Phone mount + desktop |
| Needs | Fast handoff, dark theme, wake lock |
| Journey | Paste script → QR if short → prompt |

---

## P3 — Instructor / trainer

| Attribute | Detail |
|-----------|--------|
| Goal | Reuse script across sessions on same tablet |
| Device | Single tablet |
| Needs | localStorage persistence, markdown headings for sections |
| Journey | J1 or J3 same-device |

---

## UX principles (v1)

1. **Zero account** — open and go
2. **Mobile-first** — touch targets ≥ 44px; thumb-reachable controls
3. **Obvious handoff** — show URL + OTP + QR together on desktop
4. **Fail clear** — size limits and offline states explained in plain language
5. **App-like** — installable PWA, fullscreen, minimal chrome in player

---

## Accessibility (baseline)

- Respect `prefers-reduced-motion` for scroll animations
- Keyboard operable on desktop (R12)
- Contrast ratios WCAG AA for default themes
- Screen reader: player mode announces play/pause state
