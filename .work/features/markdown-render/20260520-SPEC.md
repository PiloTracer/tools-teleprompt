# Markdown Render — Feature SPEC

**Status:** Draft  
**Owner:** eng  
**ADRs referenced:** 005  
**Related plans:** scope FR-02; foundation doc 04 §3b

---

## 1. Purpose

Convert user markdown to safe HTML for teleprompter display. Prevent XSS while supporting readable formatted scripts (headings, lists, emphasis, links).

---

## 2. In scope / Out of scope

**In scope:**

- Parse markdown subset via markdown-it
- Sanitize HTML via DOMPurify allowlist
- Plain-text escape path (no parse)
- Unit tests with XSS fixture corpus

**Out of scope:**

- WYSIWYG editor
- Raw HTML in markdown source
- DOCX/RTF conversion

---

## 3. Domain language

| Term | Definition |
|------|------------|
| Source | Raw plain or markdown string |
| Intermediate HTML | markdown-it output before sanitize |
| Safe HTML | DOMPurify output safe for DOM insertion |

---

## 4. Behavioural spec

- **R1.** Export function `renderScript(source: string, format: 'plain' | 'markdown'): SafeHtml` (or equivalent).
- **R2.** For `plain`: HTML-escape all characters; wrap in `<pre class="tp-plain">` or equivalent text container; no markdown parse.
- **R3.** For `markdown`: markdown-it with `html: false`, `linkify: true`.
- **R4.** Links rendered with `rel="noopener noreferrer"` and `target="_blank"`.
- **R5.** Pass intermediate HTML through DOMPurify with allowlist: `p, br, strong, em, u, h1-h6, ul, ol, li, a, code, pre, blockquote, hr`.
- **R6.** Strip `script`, `iframe`, `object`, `embed`, all event handlers, `javascript:` URLs.
- **R7.** React integration: use sanitized output only via approved binding; document single choke-point component `SanitizedHtml`.
- **R8.** XSS test corpus (≥10 vectors) must not execute `alert` or append `<script>` when rendered in jsdom/Playwright.

---

## 5. Data model

Stateless pure functions; no persistence.

---

## 6. APIs

Internal module API only (`frontend/src/markdown/`). No HTTP.

---

## 7. Invariants

- **I1.** No code path from user source to DOM without R5 sanitization for markdown.
- **I2.** `html: true` on markdown-it is forbidden.

---

## 8. Error model

| Condition | Behaviour |
|-----------|-----------|
| Empty source | Return empty safe fragment |
| Parse error | Fall back to escaped plain display |

---

## 9. Observability

None required v1 (client-only).
